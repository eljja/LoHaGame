# LoHaGame Original Score

All music in this directory was composed, synthesized, arranged, and rendered specifically for LoHaGame.

The score uses an original cinematic hybrid-orchestral language built from low-string ostinatos, open brass voicings, deep percussion, restrained electronic pulses, and gradual ensemble development. It does not imitate or reproduce any specific composer's composition.

- No third-party recordings, music tracks, melodies, samples, loops, or soundfonts are included.
- Instrument timbres are generated from mathematical waveforms and deterministic noise by `scripts/generate-original-score.mjs`.
- The Ogg Vorbis encoder is a build tool only and is not an audio source.
- Track metadata and technical render statistics are recorded in `manifest.json`.

These are original project assets. The LoHaGame repository owner may use, modify, and distribute them with the game without third-party audio attribution.
